# HATUA mobile (Flutter, Android first)

See the root [`README.md`](../README.md) and [`CLAUDE.md`](../CLAUDE.md) for product rules and safety boundaries.

The Android runner in `android/` is generated by `flutter create` and **tracked in Git**. Do not re-run
`flutter create` over it. If you must regenerate, diff carefully: the release manifest's INTERNET permission,
backup exclusions (`allowBackup=false`, `res/xml/data_extraction_rules.xml`) and the debug-only cleartext
config (`src/debug/res/xml/network_security_config.xml`) are deliberate edits.

```bash
flutter pub get
flutter analyze
flutter test
# Android emulator against a local Django server:
flutter run --dart-define=HATUA_API_URL=http://10.0.2.2:8000
# Physical phone over USB:
adb reverse tcp:8000 tcp:8000
flutter run --dart-define=HATUA_API_URL=http://127.0.0.1:8000
# Release builds refuse plain http; pass an https API URL:
flutter build apk --release --dart-define=HATUA_API_URL=https://api.example.invalid
```

The application ID is still the placeholder `com.example.hatua_app`. Google Play rejects `com.example.*`,
which is intentional until the owner picks a permanent ID (see `docs/DECISIONS.md`).
